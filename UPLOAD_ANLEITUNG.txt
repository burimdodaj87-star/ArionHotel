P5/P6 HOTELTRANSFERS – INSTALLATION

1. Supabase öffnen → SQL Editor → New query.
2. Datei 1_SUPABASE_HOTELTRANSFERS_AUSFUEHREN.sql vollständig kopieren und Run drücken.
3. Danach alle Dateien dieses Ordners in dasselbe GitHub-Repository hochladen und gleichnamige Dateien ersetzen.
4. supabase-config.js NICHT ersetzen oder löschen. Diese Datei bleibt mit deiner Project URL und dem Publishable Key bestehen.
5. GitHub Pages abwarten und die Webseite mit Strg + F5 neu laden.
